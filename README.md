**ReviewFlow** is a production-quality, native Visual Studio Code extension that provides an **Antigravity-style agent proposal and change review layer**.

Developed by **[Md. Rohan Islam (rohan-rusho)](https://github.com/rohan-rusho)**, ReviewFlow tracks AI agent edits, manual modifications, and external code changes in real time, presenting them as **interactive review blocks** with non-destructive Accept and Reject workflows.

---

## ⚡ The Difference from Git Diff

Git asks:
> *"What changed between two repository commits?"*

ReviewFlow asks:
> *"What did the agent propose, what has the user changed since then, and which exact parts does the user want to keep?"*

| Concept | Traditional Git Diff | ReviewFlow (Antigravity Model) |
| :--- | :--- | :--- |
| **Model** | 2-State (HEAD vs Working Tree) | **3-State (`BASE`, `PROPOSED`, live `CURRENT`)** |
| **Agent Output** | Treated as accepted text | **Treated strictly as a PROPOSAL, never truth** |
| **Reject Behavior** | Reverts whole file or chunk | **Removes ONLY the agent's delta; preserves live user edits** |
| **User Conflicts** | Git merge conflict markers | **User edits win automatically (`OVERRIDDEN`); never clobbered** |
| **Review UI** | Separate side-by-side tabs | **Unified inline diff & floating controls with zero clicks** |
| **Undo Model** | Standard `Ctrl+Z` buffer undo | **Semantic transaction history (reverses hunk, file, or workspace)** |

## 🚀 Key Features

### 1. Unified Inline Diff (Zero-Click Auto Review)
- Whenever an AI agent or edit modifies code, ReviewFlow **automatically displays the Unified Inline Diff view**:
  - **Deleted lines** highlighted in **dark red** (`#5c1d1d`) on top with `-` gutter indicators.
  - **Added lines** highlighted in **dark green** (`#1b4425`) below with `+` gutter indicators.
  - Character-level word diff highlights inside changed lines.
- No need to click external tabs or toggle separate tools—it is instantly visible in the editor.
- When all changes are resolved, ReviewFlow automatically returns to your standard clean code editor.

### 2. Independent Multi-Hunk Reviews (Accept 3, Reject 2)
If an agent modifies 5 separated places in a single file:
- Each hunk receives its own isolated floating controls:
  - `[ ✅ Accept (Alt+Enter) ]`
  - `[ ❌ Reject (Shift+Alt+Backspace) ]`
- You can accept 3 hunks and reject 2 hunks independently:
  - Accepting a hunk commits only that hunk to the baseline and clears its diff block.
  - Rejecting a hunk reverts only that hunk from the document without destroying the others.

### 3. Non-Destructive Reconciliation Engine
ReviewFlow tracks three distinct states for every proposal:
```text
BASE      → Exact content before the agent turn.
PROPOSED  → Content generated by the agent.
CURRENT   → Live VS Code document at the exact moment of decision.
```
- **Unrelated User Edits**: If you edit line 100 while an agent modified line 20, accepting or rejecting line 20 will **never touch or revert your edit on line 100**.
- **Overlapping User Edits**: If you edit the exact same region proposed by the agent, ReviewFlow marks it as `OVERRIDDEN`. **Your code wins; the agent's proposal is never forced over your work**.

### 4. Brand New File & Deletion Tracking
- **New Files**: Created files start with an empty baseline (`""`) and are rendered with 100% whole-line green additions. CodeLens prompts `[ ✅ Accept New File ]` / `[ ❌ Reject New File ]`. Rejecting a newly created file safely removes it from disk via trash.
- **Deleted Files**: Tracked as pending deletions until accepted or rejected.

### 5. Semantic Transaction Undo
Undo is not just editor `Ctrl+Z`. ReviewFlow maintains semantic multi-file transaction history:
- If you click **Accept File** (accepting 5 hunks at once), clicking **Undo Last Change** (`Alt+Shift+Z`) reverses the entire file acceptance in a single atomic step.
- If you click **Accept All** across 4 files, **Undo** restores all 4 files back to review in one transaction.
- Individual hunk accepts can be undone sequentially in exact reverse order ($C \to B \to A$).

### 6. Activity Bar Review Card & Explorer Badges
- Dedicated **ReviewFlow** activity bar view showing file lists with `+lines` / `-lines` badges and top-level **Accept All** / **Reject All** actions.
- File explorer status decorations marking modified (`M`) and new (`U`) files pending review.
- Status bar summary counter with one-click access.

## ⌨️ Keyboard Shortcuts

| Shortcut | Command | Scope |
| :--- | :--- | :--- |
| `Alt+Enter` | `ReviewFlow: Accept Change` | Active change block under cursor |
| `Shift+Alt+Backspace` | `ReviewFlow: Reject Change` | Active change block under cursor |
| `Alt+D` | `ReviewFlow: Open Inline Diff` | Toggle unified inline diff view |
| `Alt+Shift+Enter` | `ReviewFlow: Accept File` | Accept all pending changes in active file |
| `Alt+Shift+Delete` | `ReviewFlow: Reject File` | Reject all pending changes in active file |
| `Alt+Shift+]` | `ReviewFlow: Next Change` | Jump to next pending hunk |
| `Alt+Shift+[` | `ReviewFlow: Previous Change` | Jump to previous pending hunk |
| `Alt+Shift+Z` | `ReviewFlow: Undo Last Change` | Reverse last atomic review transaction |

*All keybindings can be customized in VS Code Keyboard Shortcuts (`Ctrl+K Ctrl+S`).*

## ⚙️ Extension Settings

Configure ReviewFlow in your VS Code `settings.json`:

```json
{
  "reviewflow.enabled": true,
  "reviewflow.autoShowInlineDiff": true,
  "reviewflow.preferInlineDiff": true,
  "reviewflow.showInlineActions": true,
  "reviewflow.showDecorations": true,
  "reviewflow.debounceMs": 300,
  "reviewflow.groupingDistance": 0,
  "reviewflow.persistPendingChanges": true,
  "diffEditor.renderSideBySide": false,
  "diffEditor.codeLens": true
}
```

## 📦 Installation & Packaging

### From Source
1. Clone the repository:
   ```bash
   git clone https://github.com/rohan-rusho/accept-reject_fo_VS-CODE.git
   cd accept-reject_fo_VS-CODE
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Compile the extension:
   ```bash
   npm run compile
   ```
4. Build the VSIX package:
   ```bash
   npx vsce package --no-dependencies
   ```
5. Install the VSIX in VS Code:
   ```bash
   code --install-extension reviewflow-0.1.0.vsix --force
   ```
